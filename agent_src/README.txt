GLPI Agent - Instructions
=========================

Requirements: NONE (PowerShell is built into Windows 10/11)

Launch:
  Double-click start.bat

If Windows blocks execution:
  Right-click start.bat -> Run as administrator

Auto-start with Windows:
  Win+R -> shell:startup -> copy start.bat to that folder

Logs: agent.log
Config: config.json (interval_sec, locations)
